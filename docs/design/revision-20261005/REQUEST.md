# Mobile UX revision · 5 October 2026

User direction: bottom destinations Chat, Create, Apps. Create owns unfinished app conversations; Apps owns runnable apps, with persistent pinning. The workspace advances through requirements, editable design and build without a tab strip. Preserve all editing, history, data, export, voice, recovery and background work.

Sea blue uses sea tones, warm sand surfaces and translucent navigation/composer treatments. Forest green uses deep greens and pale green surfaces. Night gray remains available. Retain the approved appearance preview and history direction.

Chat: compact keyboard-aware composer; connection status in header; a floating small latest-message button; formatted Markdown, horizontally scrolling copyable code; editable queue and interrupt-and-steer actions.

Models: installed inventory retained, imported/discovered model provenance, publisher links, collapsible catalogue for ten or fewer and a dedicated catalogue page for more. Auto-discover app-owned models; use Android folder access for external files. Explain text/vision capabilities honestly. Current JNI runtime only tokenizes text; projector files alone cannot enable multimodal inference.

Cloud: Gemini, OpenRouter, OpenAI and Claude accordions, Gemini initially expanded and at most one open. Provider-specific encrypted keys and model IDs. Generation fallback defaults on and can be disabled. No automatic cross-provider routing. Offline/manual tools hidden by default behind an advanced setting; AI-assisted template recommendation should require matching workflows and visible user choice.

Research: [Open WebUI chat features](https://docs.openwebui.com/features/chat-conversations/chat-features/), [LibreChat](https://github.com/LibreChat-AI/LibreChat), [OpenAI streaming](https://developers.openai.com/api/docs/guides/streaming-responses), [OpenRouter streaming](https://openrouter.ai/docs/api_reference/streaming), [Claude streaming](https://platform.claude.com/docs/en/build-with-claude/streaming), [Apple materials](https://developer.apple.com/design/human-interface-guidelines/materials). Patterns adapted into original Compose code; no third-party UI source copied.
